Marea Neagra — Telegram surf bot

Bot de surf pe Marea Neagra: webhook pe Vercel pentru abonări, raport orar via GitHub Actions.

Site prognoză /api/webhook /api/subscribers /api/marco

Cum funcționează

  • Vercel — webhook Telegram: userul dă /start → chat ID salvat în Redis
  • GitHub Actions — bot.py rulează orar și trimite raportul (momentan la un singur CHAT_ID)

Abonare (Vercel)

  1. Proiect pe Vercel din acest repo.
  2. Adaugă Upstash Redis (Marketplace) — UPSTASH_REDIS_REST_URL, UPSTASH_REDIS_REST_TOKEN
  3. Environment Variables: TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET, SUBSCRIBERS_API_SECRET
  4. Deploy.
  5. Leagă webhook-ul Telegram:
curl "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/setWebhook" \
  -d "url=https://surf-marea-neagra-bot.vercel.app/api/webhook" \
  -d "secret_token=${TELEGRAM_WEBHOOK_SECRET}" \
  -d "allowed_updates=[\"message\"]"

În Telegram: deschide botul → /start → ești pe listă.

Comenzi bot

Comandă Efect
/start te adaugă în lista de chat ID-uri
/stop te scoate din listă
/help comenzi

curl -H "Authorization: Bearer ${SUBSCRIBERS_API_SECRET}" \

Broadcast (GitHub Actions)

  1. Secrets: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
  2. Workflows: Hourly surf report (0 * * * * UTC) și Manual surf report
